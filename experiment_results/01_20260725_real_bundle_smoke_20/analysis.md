# 实验分析：真实数据管道小样本验证

## 目的

在正式 128 样本实验前，用 20 个真实 Amazon 共购捆绑包验证原始元数据解析、文本特征构造、变长 padding、训练与结果写入链路。

## 设置

- 数据集：AmazonReviews2014 / Sports_and_Outdoors，`related.bought_together`。
- 样本：20 个捆绑包，训练 16、验证 4；seed=2026；1 epoch；batch size 8。

## 结果

| 指标 | 结果 |
|---|---:|
| 训练对比损失 | 2.6493 |
| 验证对比损失 | 1.9239 |
| 验证主体商品 Recall@10 | 1.0000 |
| 主体商品平均注意力 | 0.4260 |

## 分析与结论

完整真实数据管道运行成功。验证集只有 4 个样本，Recall@10=1.0000 受候选数量过小影响，不具备研究解释价值。

## 局限与下一步

该实验仅作为工程 smoke test；正式分析以同日的 128 样本实验为准，后续必须继续扩大数据规模。
