# 实验分析：真实 Amazon 共购捆绑包 smoke experiment

## 目的

验证结构化 `BundleEncoder` 能否在真实 AmazonReviews2014 元数据上完成“全局文本语义 + 包内商品注意力聚合”的前向、训练和主体商品检索链路。

## 设置

- 数据集：AmazonReviews2014 / Sports_and_Outdoors；使用原始元数据的 `related.bought_together`。
- 捆绑包定义：主体商品与最多 7 个真实共购商品组成局部商品集合；主体商品的标题、描述、类目组成全局语义。
- 样本：128 个捆绑包，随机划分为训练 102、验证 26。
- 表示：局部商品使用缓存的 128 维 sentence-T5 向量；三种全局文本字段使用本实验样本拟合的 TF-IDF + SVD 向量。
- 模型：`BundleEncoder(input_dim=128, hidden_dim=128, output_dim=128)`；Adam，学习率 0.001，训练 3 epoch，seed=2026。
- 目标：以批内 InfoNCE 使捆绑包表示匹配其主体商品的 sentence-T5 表示。

## 结果

| 指标 | 结果 | 说明 |
|---|---:|---|
| 训练对比损失（epoch 1） | 3.6499 | 初始训练阶段 |
| 训练对比损失（epoch 3） | 0.9553 | 训练目标明显收敛 |
| 验证对比损失 | 3.1800 | 验证集仍存在泛化差距 |
| 验证主体商品 Recall@10 | 0.6923 | 26 个验证捆绑包中约 18 个主体进入前 10 |
| 主体商品平均注意力 | 0.4482 | 主体通常获得高于均分的局部权重 |

## 分析与结论

模型成功读取真实商品文本、真实共购关系和缓存语义向量，并支持变长局部商品集合。训练损失持续下降，说明全局—局部融合可以学习到主体商品语义；验证 Recall@10 为 0.6923，证明该表示具有初步的主体检索能力。主体平均注意力为 0.4482，表明模型没有简单平均所有商品，而是倾向将较高权重分配给主体。

## 局限与下一步

本实验规模仅 128 个捆绑包，且主体商品本身被包含在局部集合中，因此不能将 Recall@10 视为正式推荐效果，也不能证明模型识别了“核心商品—配件商品”的因果角色。下一步应扩大样本、固定按用户/时间的训练验证测试划分，并建立 Semantic Only 的 next-item 推荐任务；同时比较平均池化与注意力聚合，并输出具体商品的注意力案例。
