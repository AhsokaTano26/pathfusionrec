# 评估代码核验

实际全物品评估实现位于：

```text
02_code/sports_experiment/fullsort_eval.py
```

已确认其评估流程包括：

- 为用户构造验证或测试输入序列；
- 计算SASRec最后位置的序列表示；
- 对18,357个目录物品打分；
- 屏蔽物品0及用户历史物品；
- 计算Top-K；
- 累计HR、Recall与NDCG；
- 分别记录完整墙钟时间和核心排序时间。

验证集过滤训练历史；测试集过滤训练历史与验证交互。每位用户只有一个正样本，因此HR@K和Recall@K一致。

正式训练入口根据验证集NDCG@10保存最佳模型，并在训练结束后加载该模型进行一次测试。测试集没有进入早停条件。
