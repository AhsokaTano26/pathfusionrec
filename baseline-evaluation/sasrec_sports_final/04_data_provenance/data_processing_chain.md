# 数据处理链

现有证据能够确认的处理链为：

```text
Amazon Sports 5-core评论数据
→ 按用户聚合交互
→ 按交互时间排序
→ 用户与物品ID映射
→ all_item_seqs.json
→ sports.txt
→ leave-last-out划分
```

已核对：

- `all_item_seqs.json` 共有35,598名用户、296,337条交互；
- `id_mapping.json` 提供用户与物品映射；
- 按映射转换后的296,337条交互与 `sports.txt` 逐行一致；
- 三份处理后文件的SHA256均已保存。

限制：实验时从原始评论文件生成 `all_item_seqs.json` 的完整预处理脚本未归档。因此本包保存了原始与处理后文件的指纹以及可确认的处理逻辑，但不能仅凭本包从原始数据零起点重建全部处理结果。不会补写新脚本并将其冒充为实验时脚本。
