# SASRec Amazon Sports 任务一最终交付包

## 交付结论

本包固化了 SASRec-PyTorch（pmixer）在 Amazon Reviews 2014 Sports and Outdoors 数据集上的项目实测基线，包括实际使用的代码、三种子配置、训练记录、最佳模型、验证与测试结果、全物品评估脚本、环境记录和文件校验信息。

实验采用 leave-last-out 划分、全物品排序、`maxlen=200`、`dropout=0.2`。它适合作为本项目后续与 ActionPiece 等方法比较的 SASRec 基线，但不声称是 SASRec 原论文实验设置的严格复现版。

## 实验概况

- 用户数：35,598
- 物品数：18,357
- 总交互数：296,337
- 训练/验证/测试交互：225,141 / 35,598 / 35,598
- 随机种子：2026、2027、2028
- 选模指标：验证集 NDCG@10
- 早停：连续 20 轮无提升
- 正式测试：最佳模型确定后执行一次
- GPU：NVIDIA GeForce RTX 4090

## 校验方法

在解压后的本目录运行：

```bash
bash 09_scripts/verify_delivery_sha256.sh
```

`DELIVERY_SHA256SUMS.txt` 固化除该清单自身之外的全部交付文件。三个种子目录另有独立 `SHA256SUMS.txt`。
