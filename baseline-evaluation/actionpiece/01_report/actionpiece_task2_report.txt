ActionPiece 任务二交付报告
=========================

任务名称：核验 ActionPiece 设置对齐与充分训练
数据集：Amazon Reviews 2014 / Sports and Outdoors
正式随机种子：2024、2025、2026、2027、2028
评估方式：Leave-last-out 划分下的全物品生成式评估
实验设备：NVIDIA A800 80GB PCIe

一、核验结论
------------

1. 设置对齐核验：通过（存在公开代码运行所需的兼容性修补）。
2. 五种子运行完整性：通过。五次正式运行退出码均为 0，正式日志、有效配置、
   最佳 checkpoint、测试结果、训练时间和 GPU 记录均已保存。
3. 充分训练核验：部分通过。
   - seed 2024、2025、2026、2027 分别在第 30、28、40、34 轮停止；
   - 对应最佳验证轮次为第 10、8、20、14 轮；
   - seed 2028 训练至第 200 轮，最佳验证轮次为第 189 轮；
   - 训练曲线表明模型存在较长的平台期，前四个种子可能在后期性能提升前
     触发 patience=20 的早停。
4. 当前五种子结果可以作为阶段性复现结果，但不建议表述为“已稳定复现论文
   五种子平均性能”或“所有种子均已充分收敛”。

二、实验设置与论文/官方仓库对齐情况
------------------------------------

本次实验基于 ActionPiece 官方公开仓库，在 Amazon Sports and Outdoors 数据集
上运行。以下主要设置与论文及官方配置对齐：

- 数据集：Amazon Sports and Outdoors；
- 数据划分：leave-last-out；
- 评估方式：全物品生成式评估；
- 随机种子：2024—2028；
- 学习率：0.005；
- 权重衰减：0.15；
- warmup steps：10,000；
- dropout：0.1；
- ActionPiece 词表大小：40,000；
- 哈希桶数量：128；
- 推理分段/集成数：5；
- beam size：50；
- T5 层数：4；
- d_model：128；
- d_ff：1,024；
- attention heads：6；
- d_kv：64；
- 优化器：AdamW；
- 学习率调度：cosine；
- 最大训练轮数：200；
- 每轮验证；
- early-stop patience：20；
- 验证选模指标：NDCG@10。

公开代码在当前环境中需要以下兼容性修补：

1. 验证阶段使用与测试阶段一致的五路集成输入整理函数，以解决验证输入数量与
   n_inference_ensemble=5 不匹配的问题；
2. 修补 Amazon 压缩数据的 gzip/JSON 解析及 metadata 遍历调用；
3. 修补 Python 3.10 日志接口、tokenizer 类返回、trainer 回退和循环导入等运行问题；
4. Hugging Face 模型通过镜像下载后离线加载。

上述修改没有改变 ActionPiece 模型结构、训练目标、数据划分、测试集合、评价指标
或全物品评估口径。缓存由 seed 2026 冒烟测试阶段首次生成，随后由五个正式种子
共同复用；共同复用缓存符合仓库工作方式，但首次生成种子的顺序与 README 从
seed 2024 开始执行的顺序不同，因此在报告中予以公开说明。

四、充分训练判断
----------------

五个种子均按照相同的最大轮数和官方 patience=20 规则运行，程序正常结束。
然而，“程序按规则结束”不等同于“每个种子均已充分收敛”。

seed 2028 在训练后期才取得显著提升，并在第 189 轮达到最佳验证 NDCG@10；
前四个种子则在第 28—40 轮停止。由此可见，不同随机种子的收敛时间差异很大，
官方早停规则可能在前四个种子进入后期提升阶段之前终止训练。因此本次核验结论为：

“五个种子均完成官方早停规则下的正式训练；seed 2028 基本充分训练，
seed 2024—2027 尚不能确认充分收敛。设置对齐核验通过，充分训练核验部分通过。”

五、报告中可直接使用的描述
----------------------------

本项目基于 ActionPiece 官方公开代码，在 Amazon Sports and Outdoors 数据集上
完成 2024—2028 五个随机种子的复现实验。实验采用 leave-last-out 数据划分和
全物品生成式评估，模型结构、核心超参数、验证选模指标及评价口径与论文和官方
仓库基本对齐。为使公开代码在当前环境中正常运行，对五路验证输入、压缩数据读取
及 Python 环境兼容问题进行了必要修补，上述修改未改变模型原理、训练目标、数据
划分和评价口径。五次正式运行均正常结束并完整保存日志、配置、最佳模型和测试
结果。核验发现 ActionPiece 存在较长的平台期，seed 2024—2027 在第 28—40 轮
触发官方早停条件，seed 2028 则训练至第 200 轮并在第 189 轮取得最佳验证结果。
因此，本次实验的设置对齐核验通过，充分训练核验部分通过，当前五种子结果作为
阶段性复现结果保留。
